# Dealmarket Bis

A simulated M&A deal intelligence terminal, served as a single self-contained
HTML page.

The page carries 2,408 dispatches, 2,266 transactions, a deals screener, league
tables and company profiles. It has no external dependencies and no backend: one
file, opened in any browser, online or offline.

The transaction records are drawn from public SEC EDGAR filings, and the
financial figures attached to them come from the SEC's public XBRL data. Company
profiles and news copy outside those filings are fictional.
